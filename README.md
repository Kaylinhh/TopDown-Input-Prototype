# Arcade Pickup Game (Unity)

Small arcade game made in Unity as a portfolio project.

## Features
- New Input System (keyboard)
- Player movement with Rigidbody2D
- Pickups & score system
- Timer-based Game Over
- Persistent High Score (PlayerPrefs)
- Audio Manager (Music & SFX)
- Retry option

## Tech
- Unity 6.3
- C#
- TextMeshPro
- WebGL build
